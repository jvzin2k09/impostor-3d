# Impostor 3D

Jogo de palavras em 3D (Three.js) com bots.

## Como rodar
1. Abra a pasta no VS Code.
2. Instale a extensão **Live Server** e clique em *Go Live* (ou rode `npx serve`).

## Arquivos
- `index.html` estrutura e menus
- `style.css` estilos
- `data.js` temas e palavras (formato `palavra|dica1,dica2,dica3,dica4`)
- `scene.js` cenário 3D
- `game.js` menu e regras do jogo
